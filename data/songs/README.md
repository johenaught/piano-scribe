# Song test set (real repertoire, score-backed labels)

Four public-domain solo-piano pieces used to test the transcription chain
against *published sheet music*: the MIDI files are the same engraving as the
published score, so the labels ARE the score's notes. Audio is generated by
piano-scribe's synth renderer (additive piano-like); labels come from the
exact same MIDI — the alignment is exact by construction.

Fetched 2026-09-19 from https://ktmc.sg/apps/piano-midi-player/samples
(free public-domain piano transcriptions; licenses stated on that page).
Sheet-music PDFs for cross-checking (human eyes): pianovera.com hosts the
Mutopia engraving, e.g. `fur_elise_sheet.pdf` next to this file.

| file | piece | character | tests |
|---|---|---|---|
| fur_elise.mid | Beethoven, Für Elise | melody + arpeggiated LH | melody clarity, LH arpeggios |
| gymnopedie_1.mid | Satie, Gymnopédie No. 1 | sparse, quiet melody over sustained chords | quiet notes, pedal-ish sustains |
| moonlight_mvt1.mid | Beethoven, Moonlight Sonata Mvt 1 | constant broken-chord motion | repeated patterns, left-hand density |
| canon_in_d.mid | Pachelbel, Canon in D (piano arr.) | continuous arpeggio patterns | repetitive arpeggios, high note density |

## How to check

- Detected-vs-score: `python scripts/evaluate_song.py data/songs/*.mid`
  (report includes missed notes + phantom notes with times/confidences).
- Sheet-music comparison (returns human eyeball check): open any score of
  the piece (the PDF for Für Elise is included) and play the exported MIDI
  from the app; note-by-note diff is above.

## Expectation (per outline §8)

This is an offline recall-priority check: *did every note played make it*,
and *are there notes that were never played*. Timing tolerance for matching:
onset ±50 ms. No accuracy promise is claimed from these numbers alone —
real recordings remain the final judge — but score-hard failures (a note
that should be there is not) are what this set exists to catch.
